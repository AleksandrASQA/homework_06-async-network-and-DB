# Домашнее задание: Асинхронная работа с сетью и БД

Цель: реализовать асинхронное получение данных с внешнего API и их сохранение в базу данных с установлением связей между моделями.

## 🛠 Технологии и зависимости

- **Python 3.10+**
- **aiohttp** – для асинхронных HTTP-запросов к API
- **SQLAlchemy >= 1.4** – для работы с базой данных (Asyncio API)
- **aiosqlite** – асинхронный драйвер для SQLite
- **pytest** и **pytest-asyncio** – для написания и запуска автотестов

## 📁 Структура проекта

- `main.py` – точка входа в приложение. Оркестрирует создание таблиц, конкурентную загрузку данных и их сохранение в БД.
- `models.py` – конфигурация асинхронного `engine`, фабрика `AsyncSession` и declarative-модели `User` и `Post` с настроенными связями (`relationship`).
- `jsonplaceholder_requests.py` – модуль с асинхронными функциями для получения данных с JSONPlaceholder API (с переиспользуемой базовой функцией `fetch_json`).
- `test_homework_6.py` – набор автотестов, проверяющих корректность запросов, сохранения данных и работы связей между моделями.
- `requirements.txt` – список зависимостей проекта.
